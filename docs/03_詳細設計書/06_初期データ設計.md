# 業務管理システム 詳細設計書 06_初期データ設計

## 1. 初期データ設計

`DatabaseSeeder` により、開発・学習用データを投入します。

| 種別 | 内容 |
| --- | --- |
| 管理者ユーザー | `admin@example.com` / `password` |
| 担当者ユーザー | `staff@example.com` / `password` |
| 顧客 | サンプル顧客3件 |
| 案件 | 進行中案件と予定案件 |
| タスク | 期限間近のサンプルタスク |

同じSeederを複数回実行しても重複しにくいよう、`updateOrCreate()` を使用しています。
