# 業務管理システム 詳細設計書 01_技術構成とルーティング

## 1. 文書の目的

本書は、業務管理システムサンプルのAPI、Controller、DB、Model、React側処理を実装単位に近い粒度で整理した文書です。

対象コードは主に次のファイルです。

- `backend/routes/api.php`
- `backend/app/Http/Controllers/Api/*Controller.php`
- `backend/app/Models/*.php`
- `backend/database/migrations/*.php`
- `frontend/src/App.tsx`
- `frontend/src/api/client.ts`
- `frontend/src/types.ts`

## 2. 技術構成

| 分類 | 内容 |
| --- | --- |
| バックエンド | PHP 8.3、Laravel 13、Laravel Sanctum |
| フロントエンド | React 19、TypeScript、Vite、lucide-react |
| データベース | MySQL 9.7.0 |
| テスト | PHPUnit、Laravel Feature Test |
| 実行 | Docker Compose |

## 3. ルーティング設計

`backend/routes/api.php` では、ログインAPIだけを未ログインでも呼べるAPIとして定義しています。

| グループ | 対象 | ミドルウェア |
| --- | --- | --- |
| 認証前 | `POST /api/login` | なし |
| 認証後 | logout、me、dashboard、customers、projects、tasks | `auth:sanctum` |

`customers`、`projects`、`tasks` は `Route::apiResource()` で定義されています。そのため、一覧、詳細、登録、更新、削除の標準的なREST APIが作られます。
