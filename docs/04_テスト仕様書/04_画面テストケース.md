# 業務管理システム テスト仕様書 04_画面テストケース

## 1. 画面テストケース

| ID | 観点 | 操作 | 期待結果 |
| --- | --- | --- | --- |
| TC-UI-001 | 初期表示 | `http://localhost:5173` を開く | 未ログインならログイン画面が表示される |
| TC-UI-002 | ログイン | 初期ユーザーでログイン | ダッシュボードが表示される |
| TC-UI-003 | タブ切り替え | サイドバーの各ボタンを押す | 対象画面に切り替わる |
| TC-UI-004 | 顧客登録 | 顧客フォームを入力して登録 | 一覧に追加され、ダッシュボード件数が更新される |
| TC-UI-005 | 案件登録 | 顧客を選択して案件登録 | 一覧に追加され、顧客名と金額が表示される |
| TC-UI-006 | タスク登録 | 案件を選択してタスク登録 | 一覧に追加され、案件名と期限が表示される |
| TC-UI-007 | 編集 | 一覧の編集ボタンを押して保存 | 更新後の内容が一覧に反映される |
| TC-UI-008 | 管理者削除 | `admin` で削除ボタンを押し確認OK | 対象データが一覧から消える |
| TC-UI-009 | 担当者削除不可 | `staff` でログイン | 削除ボタンが表示されない |
| TC-UI-010 | エラー表示 | 必須項目を空で送信 | エラーメッセージが表示される |
| TC-UI-011 | 再読み込み | 再読み込みボタンを押す | 最新のダッシュボード、顧客、案件、タスクが再取得される |
| TC-UI-012 | ログアウト | ログアウトボタンを押す | ログイン画面へ戻り、画面側の業務データが空になる |
