# 業務管理システム テスト仕様書 02_既存自動テスト

このリポジトリは `backend/` を自分で作る学習状態です。本書のテストは、[Laravel 学習ステップ](../05_Laravel学習ステップ/01_学習ロードマップ.md) に沿って `backend/` を作成した後に実装する到達目標です。

## 1. 既存自動テストとの対応

| テストファイル | テスト名 | 確認内容 |
| --- | --- | --- |
| `AuthApiTest.php` | `test_login_returns_authenticated_user` | 正しい認証情報でログインでき、ユーザー情報が返ること |
| `AuthApiTest.php` | `test_login_rejects_invalid_credentials` | パスワード誤りでログインできないこと |
| `AuthApiTest.php` | `test_guest_cannot_access_business_api` | 未ログインで業務APIにアクセスできないこと |
| `BusinessApiTest.php` | `test_customer_project_and_task_can_be_created` | 顧客、案件、タスクを順番に作成できること |
| `BusinessApiTest.php` | `test_staff_cannot_delete_business_records` | `staff` は削除できないこと |
| `BusinessApiTest.php` | `test_admin_can_delete_business_records` | `admin` は削除できること |
| `BusinessApiTest.php` | `test_dashboard_summary_returns_counts` | ダッシュボード集計が件数を返すこと |
