# 業務管理システム 要件定義書 03_機能要件

## 1. 認証機能

| 要件ID | 要件 |
| --- | --- |
| FR-AUTH-001 | 利用者はメールアドレスとパスワードでログインできる。 |
| FR-AUTH-002 | ログイン成功時、サーバーはログインユーザー情報を返す。 |
| FR-AUTH-003 | 画面読み込み時、既存セッションがあればログイン状態を復元できる。 |
| FR-AUTH-004 | 利用者はログアウトできる。 |
| FR-AUTH-005 | 未ログイン利用者は業務APIを利用できない。 |

初期ユーザーは次のとおりです。

| 権限 | メールアドレス | パスワード |
| --- | --- | --- |
| 管理者 | `admin@example.com` | `password` |
| 担当者 | `staff@example.com` | `password` |

## 2. ダッシュボード機能

| 要件ID | 要件 |
| --- | --- |
| FR-DASH-001 | 顧客数、案件数、未完了タスク数を表示できる。 |
| FR-DASH-002 | 案件ステータスごとの件数を表示できる。 |
| FR-DASH-003 | 期限が7日以内の未完了タスクを最大5件表示できる。 |
| FR-DASH-004 | 再読み込みボタンで最新データを取得できる。 |

## 3. 顧客管理機能

| 要件ID | 要件 |
| --- | --- |
| FR-CUS-001 | 顧客一覧を表示できる。 |
| FR-CUS-002 | 顧客を新規登録できる。 |
| FR-CUS-003 | 顧客を編集できる。 |
| FR-CUS-004 | 管理者は顧客を削除できる。 |
| FR-CUS-005 | 担当者は顧客を削除できない。 |
| FR-CUS-006 | 顧客一覧には顧客に紐づく案件数を表示できる。 |

顧客状態は次の値を使用します。

| 保存値 | 画面表示 |
| --- | --- |
| `prospect` | 見込み |
| `active` | 取引中 |
| `inactive` | 停止 |

## 4. 案件管理機能

| 要件ID | 要件 |
| --- | --- |
| FR-PRJ-001 | 案件一覧を表示できる。 |
| FR-PRJ-002 | 顧客を選択して案件を新規登録できる。 |
| FR-PRJ-003 | 案件を編集できる。 |
| FR-PRJ-004 | 管理者は案件を削除できる。 |
| FR-PRJ-005 | 担当者は案件を削除できない。 |
| FR-PRJ-006 | 案件一覧には顧客名、状態、金額、期間を表示できる。 |
| FR-PRJ-007 | 案件登録時に担当者が未指定の場合、ログイン中の利用者を担当者にする。 |

案件状態は次の値を使用します。

| 保存値 | 画面表示 |
| --- | --- |
| `planned` | 予定 |
| `in_progress` | 進行中 |
| `completed` | 完了 |
| `on_hold` | 保留 |

## 5. タスク管理機能

| 要件ID | 要件 |
| --- | --- |
| FR-TSK-001 | タスク一覧を表示できる。 |
| FR-TSK-002 | 案件を選択してタスクを新規登録できる。 |
| FR-TSK-003 | タスクを編集できる。 |
| FR-TSK-004 | 管理者はタスクを削除できる。 |
| FR-TSK-005 | 担当者はタスクを削除できない。 |
| FR-TSK-006 | タスク一覧には案件名、期限、状態、担当者を表示できる。 |
| FR-TSK-007 | タスク登録時に担当者が未指定の場合、ログイン中の利用者を担当者にする。 |

タスク状態は次の値を使用します。

| 保存値 | 画面表示 |
| --- | --- |
| `todo` | 未着手 |
| `doing` | 対応中 |
| `done` | 完了 |
