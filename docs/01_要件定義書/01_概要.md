# 業務管理システム 要件定義書 01_概要

## 1. 文書の目的

本書は、React SPA と Laravel API で構成された「業務管理システムサンプル」の要件を整理した文書です。

このシステムは、顧客、案件、タスクをまとめて管理する学習・引継ぎ向けのサンプル業務システムです。実装済みの機能を正として記載し、未実装の理想機能は「今後の課題」として分けて扱います。

## 2. システムの目的

本システムの目的は、営業・業務担当者が顧客情報、案件情報、案件に紐づくタスクを一元管理できるようにすることです。

主な目的は次のとおりです。

- 顧客、案件、タスクを画面から登録・編集・確認できるようにする。
- 管理者だけが削除できるようにし、誤削除のリスクを下げる。
- ダッシュボードで件数や期限間近のタスクを確認できるようにする。
- React、Laravel、MySQL、Docker Compose を使った業務アプリの構成を学習しやすくする。
