# 業務管理システム 仕様書 目次

このディレクトリには、React SPA と Laravel API で構成された業務管理システムサンプルの仕様書を格納しています。
現在のリポジトリは `backend/` を自分で作る学習状態のため、実装前に「05. Laravel学習ステップ」も参照してください。

各仕様書は、読みやすい範囲で章ごとに分割しています。まず全体像を知りたい場合は要件定義書から順番に読み、実装の詳細を確認したい場合は詳細設計書を参照してください。仕様書そのものの作り方を学びたい場合は「06. 仕様書作成学習ステップ」から読むと流れをつかみやすくなります。
