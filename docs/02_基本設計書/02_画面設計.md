# 業務管理システム 基本設計書 02_画面設計

## 1. 画面構成

| 画面 | 概要 | 主な操作 |
| --- | --- | --- |
| ログイン画面 | メールアドレスとパスワードでログインする。 | ログイン |
| ダッシュボード | 業務データの集計を確認する。 | 件数確認、期限間近タスク確認、再読み込み |
| 顧客管理 | 顧客情報を管理する。 | 一覧、登録、編集、削除 |
| 案件管理 | 顧客に紐づく案件を管理する。 | 一覧、登録、編集、削除 |
| タスク管理 | 案件に紐づくタスクを管理する。 | 一覧、登録、編集、削除 |

ログイン後は左側のサイドバーで画面を切り替えます。削除ボタンは `admin` でログインした場合だけ表示します。
