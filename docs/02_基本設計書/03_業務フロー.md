# 業務管理システム 基本設計書 03_業務フロー

## 1. ログイン

1. 利用者がログイン画面でメールアドレスとパスワードを入力する。
2. React が `/sanctum/csrf-cookie` を呼び、CSRF Cookie を取得する。
3. React が `POST /api/login` を呼ぶ。
4. Laravel が認証に成功した場合、セッションを再生成してユーザー情報を返す。
5. React がダッシュボード、顧客、案件、タスクのデータを読み込む。

## 2. 画面初期表示

1. React が `GET /api/me` を呼び、既存Cookieでログイン済みか確認する。
2. ログイン済みであれば、業務データをまとめて読み込む。
3. 未ログインであれば、ログイン画面を表示する。

## 3. 顧客・案件・タスクの登録と編集

1. 利用者がフォームに入力する。
2. React が登録時は `POST`、編集時は `PUT` で API を呼ぶ。
3. Laravel が入力値を検証する。
4. 検証成功時はDBへ保存し、保存後のデータをJSONで返す。
5. React が一覧とダッシュボードを再読み込みする。

## 4. 削除

1. `admin` 利用者が削除ボタンを押す。
2. React が確認ダイアログを表示する。
3. OKの場合、React が `DELETE` API を呼ぶ。
4. Laravel がログインユーザーの `role` を確認する。
5. `admin` であれば削除し、`staff` であれば `403 Forbidden` を返す。
