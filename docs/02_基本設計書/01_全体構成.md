# 業務管理システム 基本設計書 01_全体構成

## 1. 文書の目的

本書は、業務管理システムサンプルの全体構成、画面、API、データ、認証・認可の基本設計をまとめた文書です。

詳細なバリデーションやController単位の処理は、`docs/03_詳細設計書/` に記載します。

## 2. システム全体構成

本システムは、ブラウザで動作する React SPA、JSON API を提供する Laravel、データを保存する MySQL で構成します。

```text
ブラウザ
  ↓ HTTP / Cookie
React + Vite
  ↓ fetch API
Laravel API + Sanctum
  ↓ Eloquent ORM
MySQL
```

| 層 | 技術 | 役割 |
| --- | --- | --- |
| フロントエンド | React 19、Vite、TypeScript | 画面表示、フォーム入力、API呼び出し |
| バックエンド | Laravel 13、Sanctum | 認証、認可、業務API、入力チェック |
| データベース | MySQL 9.7.0 | ユーザー、顧客、案件、タスク、セッションの保存 |
| 実行環境 | Docker Compose | 開発用コンテナの起動と接続 |

Docker Compose で起動した場合の主なURLは次のとおりです。

| 対象 | URL |
| --- | --- |
| React画面 | `http://localhost:5173` |
| Laravel API | `http://localhost:8000` |
